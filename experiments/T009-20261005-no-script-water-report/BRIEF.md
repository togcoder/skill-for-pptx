# T009 Arm C — frozen no-script brief

## Input shown to planner

- One existing 10-slide PPTX.
- High-level instruction: “Làm bài thuyết trình này rõ ràng, mạch lạc và có chuyển động chuyên nghiệp.”
- No object-by-object animation script.
- Speaker notes and existing timing are absent in the source inventory.

## Frozen hypothesis

A narrative-first planner can infer defensible slide objectives and presenter click beats from visible titles, reading order and layout while preserving all source content. It should not animate raw z-order or synthesize components when existing shape boundaries are sufficient.

## Frozen acceptance

1. Ten source slides remain ten slides in the same order.
2. Source text, geometry, theme/media and non-timing package parts remain unchanged.
3. Every click advances one audience idea; paired alternatives use separate clicks.
4. Automatic stages may continue within a click; no guessed speech delay.
5. No generated components unless a documented resource gap requires one.
6. Static renders are reviewed but do not count as native playback.
7. Native playback remains unverified without the exact candidate in Microsoft PowerPoint.
