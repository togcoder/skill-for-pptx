# Multi-Domain Aesthetic Knowledge Repository (`knowledge/taste/`)

This directory is the persistent, lab-wide knowledge repository for aesthetic taste, visual design rules, craftsmanship formulas, and multi-domain design intelligence, created under task **T086 [cross]**.

## Purpose & Scope
This repository answers the core question:
> *What are the universal, crowd-tested visual principles across world-class disciplines (presentations, vector graphics, 3D, CAD/industrial design, motion design, Swiss typography, web AI skills, data visualization, and cinematography) that can be translated into concrete, verifiable guidance for PowerPoint (PPTX)?*

In accordance with Decisions **D001**, **D009**, **D010**, and **D011**:
- **D001 & D009:** Final quality is evaluated by opening and flipping slides in Microsoft PowerPoint.
- **D010:** Researched crowd taste, written in our own words, verified through blind testing, never copied verbatim.
- **D011:** A skill is written design guidance (written like a master craftsman/teacher); code is merely its toolbox.
