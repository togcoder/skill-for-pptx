## Defects found in the uncommitted author changes, fixed before merge

1. **Number gate was fixed in the wrong place.** Recording both readings in `_numbers` still required both
   strings to exist; a legitimate `156.179` → `156179` formatting change would fail. Moved the equivalence to
   the comparison (`_number_variants`) so either reading keeps the number, while a real loss still fails.
2. **Guide still said `check` 9/9** while the gate count is now 12 with `--map`. Corrected in guide 11.
3. **Chart gate only checked chart type**, so a redrawn chart with invented values could pass — exactly the
   owner's "bịa biểu đồ" complaint. Added `chart data kept` (categories + values signature), with a test.

## Residual risks / deliberately deferred

- `chart data kept` compares category/value signatures; a legitimate series rename does not fail (names are not
  compared), but a deliberate data change does. Reordered series are accepted because values are sorted.
- `tables kept` counts native tables, not visible borders; "table without borders" still needs a visual/contrast
  gate.
- The self-audit's P0 `compare OLD NEW` command, pixel contrast, image occlusion and semantic text/video-pair
  gates are **not** in this PR. They are accepted as the next task; `check` remains a minimum gate, not a
  quality score (guide 11).
- Real-deck verification is rung 4/5 (PowerPoint opens and renders); owner scoring is still rung 6 and pending
  for any rebuilt deck.
